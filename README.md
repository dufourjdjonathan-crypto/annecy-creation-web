# Annecy Création Web

Identité visuelle d'Annecy Création Web (création de sites, logiciels sur mesure, SEO).

## Logo — pistes

`logo/concepts/concepts.png` présente les trois pistes :

- **A — Reflet** (recommandée) : les chevrons du code `< >`, pivotés, forment la montagne et son reflet dans le lac.
- **B — Curseur** : un A en forme de montagne, dont la barre flotte comme un curseur.
- **C — Lignes de lac** : sous les sommets, la surface du lac est faite de lignes de code indentées.
